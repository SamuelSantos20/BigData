# 📊 Projeto Big Data — Senac

Projeto desenvolvido durante minha formação em **Big Data no Senac**, com foco na aplicação prática de conceitos e ferramentas voltadas para **dados, processamento, análise e geração de insights**.

A proposta deste repositório é reunir as etapas desenvolvidas ao longo do projeto, desde a organização e tratamento dos dados até a construção das análises e soluções implementadas.

## 🚀 Sobre o projeto

Durante o desenvolvimento, serão trabalhados conceitos como:

- 📥 Coleta e organização de dados
- 🧹 Limpeza e tratamento de dados
- 🔄 Transformação e processamento
- 📊 Análise exploratória
- 📈 Visualização de dados
- 🗄️ Manipulação de bases de dados
- 🧠 Geração de insights a partir dos dados

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos no curso em um projeto prático, simulando etapas presentes em projetos reais de **Data Analytics e Big Data**.

## 🛠️ Tecnologias

As tecnologias utilizadas serão adicionadas e atualizadas conforme o desenvolvimento do projeto.

`Python` • `SQL` • `Pandas` • `Jupyter Notebook` • `Banco de Dados` • `Big Data`
